# 작업 기록

[PLAN](../PLAN.md)의 항목 번호에 연결해 결과를 기록한다. 날짜는 Asia/Seoul 기준이다. 실제 작업한 날에 주요 결과·검증·리뷰 결과를 짧게 남기고, 같은 날 같은 항목의 후속 결과는 해당 행에 정리한다. 리뷰는 검토 범위와 발견한 문제·처리를 기록하며, 자체 리뷰와 외부 리뷰를 구분한다.

여러 날에 걸친 작업은 날짜마다 같은 계획 번호로 기록하며 이전 날짜의 결과를 보존한다. 자세한 규칙은 [AGENTS](../AGENTS.md#일일-계획과-이어서-작업하기)를 따른다.
