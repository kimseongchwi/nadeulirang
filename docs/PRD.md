# 제품 요구사항 (PRD)

상태: 첫 공개 범위 확정 · 확정일·갱신일: 2026-10-02

PRD는 Product Requirements Document, 제품 요구사항 문서다. 무엇을 만들고 어떤 동작을 충족해야 하는지 정의한다. 작업 순서·진행 체크는 [PLAN의 P05](../PLAN.md#요구사항과-디자인)에서 관리한다. 사용자가 선택한 다섯 종류 통합 검색·최대 3곳 비교·예상 합계 후속 범위를 기준으로 대상 사용자와 기능별 완료 기준을 정리했다.

## 서비스 목표

전국 축제·행사·전시·박물관·문화관광지의 일정·요금·할인 조건을 검색·비교한다. 개인 프로젝트로 운영하며 검색 유입과 광고 수익을 목표로 한다. 여러 공식 사이트에서 방문 조건을 반복 확인하는 불편을 줄인다.

## 대상 사용자와 방문 시나리오

주 대상은 국내 당일 나들이를 준비하는 성인이다. 혼자·동반자·아이와 방문할 곳을 찾으며, 방문 가능한 날짜와 일반 입장료·추가 요금·할인 조건을 공식 출처로 확인하려는 사용자를 우선한다. 숙박·교통 경로·여행 일정표 구성은 첫 공개 범위에 포함하지 않는다.

| 시나리오 | 사용자의 목표 | 완료 판단 |
|---|---|---|
| 주말 후보 찾기 | 지역과 방문 날짜로 축제·행사 또는 시설 후보를 찾는다. | 조건에 맞는 후보와 일정의 확인 여부를 볼 수 있고 검색 URL을 다시 열어 같은 조건을 복원한다. |
| 동반 방문 조건 확인 | 박물관·전시의 일반 입장료, 아이 관련 할인과 별도 체험료·예약 조건을 확인한다. | 일반 요금과 추가 요금이 구분되고, 누락된 할인·증빙·예약 조건은 미확인으로 표시되며 공식 링크로 이동할 수 있다. |
| 후보 비교 후 결정 | 최대 3곳의 방문 가능 여부와 요금 조건을 같은 날짜로 비교한다. | 동일한 항목으로 차이와 미확인 정보를 읽고, 상세 또는 공식 출처로 이동할 수 있다. |

## 첫 공개 범위

대상 종류는 축제·행사·전시·박물관·문화관광지다. 서비스의 장기 목표는 전국 검색이며 첫 공개에서 실제 노출하는 지역·종류·건수는 P06에서 확보한 데이터에 맞춘다. 확보하지 못한 지역을 지원 지역으로 표시하지 않는다.

| 기능 | 기대 동작 |
|---|---|
| 검색·목록 | 이름 키워드·시도·종류·방문 날짜 1일·일반 입장료 구분으로 검색. 조건과 페이지를 URL에 유지 |
| 상세 | 행사 일정 또는 시설 운영 정보, 주소·일반 요금·추가 요금·할인·예약 조건·출처·확인 시각 제공 |
| 비교 | 2~3곳을 같은 방문 날짜와 일반 입장 기준으로 비교. 후보 제거와 상세 이동 제공 |
| 검색 유입 | 유효한 상세·지역·종류 페이지의 본문 HTML·고유 메타데이터 제공. 색인·sitemap 검증은 P14에서 수행 |

요금은 공지된 단가와 조건을 표시한다. 인원·연령 입력, 할인 자격 자동 판정, 예상 합계 계산은 첫 공개에서 제외한다. 확인하지 못한 요금 조건으로 합계를 계산하지 않는다.

로그인·결제·직접 예약·리뷰·실시간 잔여석·알림·네이티브 앱·지도 검색·거리순 추천은 첫 공개에서 제외한다. 예약은 공식 예약 안내 또는 공식 사이트로 연결한다. 광고 배치와 정책 검증은 P07·P15에서 다룬다.

## 기능별 완료 판단 기준

### 검색·목록

- 키워드는 이름의 부분 일치로 찾는다. 시도·종류·요금은 각각 하나씩 선택하며 모든 선택 조건을 함께 적용한다. 방문 날짜는 선택 사항이다. 공백 키워드는 미입력으로 처리한다.
- 요금 필터는 할인 없는 일반 성인 입장 기준으로 무료·유료·미확인을 구분한다. 무료 입장에 유료 체험이 있는 경우 목록에도 별도 요금 존재를 표시한다. 일반 요금의 기준이 불명확하면 미확인으로 분류한다.
- 방문 날짜는 Asia/Seoul의 오늘 이후 달력 날짜이며 오늘을 포함한다. 과거 날짜는 유효하지 않은 조건으로 처리한다. 기간 행사는 시작일과 종료일을 포함하고 확인된 휴무·취소를 반영해 일치 여부를 판단한다. 상설 시설은 확인된 운영 요일·휴관일·임시 휴관을 적용한다. 상설 시설도 날짜·운영 조건을 확인하지 못하면 방문 가능으로 추정하지 않는다.
- 날짜를 선택했을 때 그날 운영이 확인된 후보만 결과에 포함한다. 운영 여부를 판단할 수 없어 제외된 후보가 있다면 그 사실을 안내한다. 날짜 조건을 해제하면 해당 후보를 일정 미확인 표시와 함께 찾을 수 있다.
- 취소된 행사와 종료된 기간 행사는 일반 검색에서 제외한다. 저장된 상세 URL에서는 취소·종료 상태와 출처를 볼 수 있다. 상태 판정에 필요한 정보가 누락되면 상태 미확인으로 표시한다.
- 날짜가 없는 검색은 진행 중·예정 기간 행사를 시작일 순으로, 이후 상설 시설을 이름 순으로 보여주고 일정·상태 미확인 후보는 마지막에 이름 순으로 보여준다. 날짜가 있는 검색은 해당 날짜의 기간 행사를 시작일 순으로, 이후 상설 시설을 이름 순으로 보여준다. 동일한 이름·시작일은 안정된 식별자로 순서를 유지한다. 페이지당 20개를 제공한다.
- URL에 키워드·지역·종류·날짜·요금·페이지를 보존한다. 새로고침·직접 접속·브라우저 뒤로 가기에서 조건을 복원하고, 조건 변경 시 첫 페이지로 이동한다.
- 유효하지 않은 날짜·필터·페이지 값은 기본값으로 정리하고 적용된 조건과 URL이 일치해야 한다. 요청 실패를 결과 0건으로 표시하지 않는다.
- 목록에 이름·종류·지역·기간 또는 상설 구분·일반 입장료 구분·상태를 표시한다. 로딩, 결과 없음, 조회 실패를 구분하고 조건 초기화·재시도를 제공한다.

### 상세

- 이름·종류·지역·주소와 행사 기간 또는 시설 운영 정보를 제공한다. 운영 시간·휴관일·예약 기간은 서로 분리한다. 확인되지 않은 값은 항목별 미확인으로 표시한다.
- 일반 요금은 대상별 단가와 적용 기준을 표시한다. 특별전·체험·주차 등 확인된 추가 요금은 일반 요금과 분리한다. 할인은 대상·기간·증빙·중복 가능 여부를 표시하며 누락된 조건을 채워 넣지 않는다.
- 대표 출처와 항목별 출처가 다르면 해당 정보에서 출처를 찾을 수 있어야 한다. 수집 시각과 마지막 원천 확인 시각을 구분한다. 원천 확인은 원천 응답을 마지막으로 확인한 시각이며 현장 운영을 보증하지 않는다.
- 변경·취소·종료·수집 실패를 구분한다. 갱신 실패 시 마지막으로 확보한 정보를 유지하고 갱신 실패와 마지막 성공 시각을 표시한다. 실패만으로 행사 취소를 추정하지 않는다.
- 존재하지 않는 식별자는 찾을 수 없음으로 응답한다. 일시적인 조회 실패는 오류와 재시도를 제공하며 찾을 수 없음으로 처리하지 않는다.
- 공식 안내·예약 링크를 제공한다. 원천에 공식 예약 링크가 없으면 직접 예약 기능이나 예약 가능 여부를 만들어 표시하지 않는다.

### 비교

- 목록·상세에서 최대 3개를 선택한다. 같은 후보의 중복 선택을 막고, 네 번째 후보를 선택하면 기존 후보 제거가 필요함을 안내한다. 2개 이상일 때 비교를 실행할 수 있다.
- 비교 후보 식별자와 방문 날짜를 URL에 보존해 새로고침·직접 접속으로 복원한다. 날짜의 유효성은 검색과 같은 기준으로 처리한다. 검색 화면의 현재 페이지는 비교 후보를 제한하지 않는다.
- 이름·지역·종류·기간 또는 운영 조건·선택 날짜의 운영 여부·일반 요금·추가 요금·할인·예약 조건·출처·확인 시각을 동일한 항목으로 표시한다.
- 날짜 미선택 시 운영 여부는 날짜 미선택으로 표시한다. 선택한 날짜의 운영 여부는 가능·불가·미확인을 구분하며 예약 가능이나 잔여석 확보로 표현하지 않는다.
- 할인 자격을 자동 적용하지 않고 대상별 공지 요금을 나란히 보여준다. 미확인 항목을 0원이나 할인 없음으로 치환하지 않으며 최저가 순위·개인별 합계를 제공하지 않는다.
- 후보를 제거하고 상세로 이동할 수 있다. URL의 중복 식별자는 하나로 정리하고 3개 초과 시 앞의 3개만 유지해 안내한다. 삭제·존재하지 않는 후보는 안내 후 제외하고, 2개 미만이면 재선택 안내를 제공한다. 일시적인 조회 실패는 후보를 지우지 않고 오류·재시도를 제공한다.

### 검색 유입과 공개 확인

- 상세·확보된 지역·종류 페이지는 본문 HTML과 고유 제목·설명을 제공한다. 없는 데이터로 지역 소개나 행사 정보를 생성하지 않는다.
- 조합 필터·비교·빈 결과·오류 URL의 색인 정책과 canonical·sitemap 세부 기준은 P14에서 정한다. 잘못된 상세 URL은 정상 상세처럼 색인시키지 않는다.
- P13 완료 시 위 세 시나리오를 실제 확보 데이터로 검증한다. 무료·유료·미확인 요금, 추가 요금·할인 누락, 행사 시작·종료일, 시설 휴관일, 취소·종료, 빈 결과·조회 오류, URL 복원, 비교 중복·개수 제한·후보 삭제를 확인한다. 가격·날짜 판정 로직의 필요한 테스트는 각 구현 항목에서 둔다.

## 정보·계산 기준

- 무료·유료·미확인을 구분하며 누락된 요금을 무료로 바꾸지 않는다.
- 일반 관람료와 특별전·체험 요금을 분리하고 할인 대상·기간·증빙·중복 여부를 표시한다.
- 후속 예상 합계 기능도 조건이 모두 확인된 경우에만 계산한다. 첫 공개에서는 합계를 제공하지 않으며, 조건부 최저 요금을 모든 방문자의 실제 결제 금액으로 표시하지 않는다.
- 상설 시설과 기간 행사를 구분하고 날짜·운영 시간·예약 기간을 분리한다. 기준 시간대는 Asia/Seoul이다.
- 출처 URL·원본 식별자·수집 및 확인 시각을 보존하고 저장된 데이터를 조회한다. 수집 실패·변경·취소 상태를 구분한다.
- 실제 확보한 지역·시설·정보의 범위를 표시한다. 모든 시설과 모든 할인 정보를 확보했다고 표현하지 않는다.

## 데이터 확보와 후속 결정

2026-10-02 사용자는 축제·행사·전시·박물관·문화관광지를 함께 검색하고 최대 3곳의 일정·요금 조건을 비교하며 예상 합계 계산은 후속으로 두는 범위를 선택했다. 이 범위의 검색·상세·비교 완료 기준은 위 항목을 따른다.

P06에서 첫 원천과 행사·시설 표본을 검증한다. 노출 후보는 최소한 원본 식별자·이름·종류·시도·출처 URL·수집 시각을 확보해야 한다. 주소·일정·요금·할인·예약 정보의 누락은 명시한다. 날짜 필터에는 운영을 확인한 후보만 포함하고 요금 누락은 미확인으로 분류한다. 누락 때문에 대표 시나리오가 성립하지 않으면 지원 종류·지역·기능을 P05에서 다시 검토한다.

원천의 필드·갱신 주기·호출 제한·상업적 이용·이미지 조건, 행사와 시설의 중복 식별, 공개 가능한 표본 범위는 P06에서 확인한다. 원천별 갱신 주기·오래된 정보 표시 기준·취소 판정 근거는 P06 결과를 바탕으로 P11 구현 전에 정한다. 이미지 사용 권한을 확인하지 못한 후보도 텍스트 정보로 열람할 수 있어야 한다.

P07에서 검색·상세·비교의 배치와 상태를 검토한다. 이 문서의 기능 범위 선택은 DESIGN의 색상·폰트·화면 시안을 확정하는 작업을 대신하지 않는다.

색상·폰트·화면 형태는 [DESIGN](../DESIGN.md), 작업 순서와 완료 기준은 [PLAN](../PLAN.md)에서 관리한다.
