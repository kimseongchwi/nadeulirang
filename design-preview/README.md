## 다시 실행하기

저장소 루트 `C:\myWork\nadeulirang`에서 실행한다. 별도 패키지 설치는 필요 없다.

```powershell
node design-preview/server.cjs
```

서버가 실행 중일 때 이 PC에서 접속할 수 있다. 종료는 Ctrl+C다. 이미 8916 포트를 쓰는 검토 서버가 실행 중이면 기존 서버를 이용하거나 먼저 종료한다.

검토·완료 상태는 [PLAN](../PLAN.md), 디자인 기준은 [DESIGN](../DESIGN.md), 사진 출처는 [이미지 이용 안내](assets/IMAGE-CREDITS.md)에서 관리한다.
